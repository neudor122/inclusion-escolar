# Inclusão Escolar

Sistema web para gerenciamento de acompanhamento de alunos da educação inclusiva.
O projeto tem como objetivo facilitar o registro de alunos, profissionais responsáveis e atendimentos realizados pela equipe escolar.

# 🚀 Funcionalidades

Atualmente o sistema possui:

✅ Cadastro de alunos  
✅ Lista de alunos cadastrados  
✅ Registro de atendimentos  
✅ Histórico de acompanhamentos  
✅ Armazenamento local dos dados  
✅ Interface responsiva para celulares  
✅ Funcionamento como aplicativo PWA  


# 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Progressive Web App (PWA)
